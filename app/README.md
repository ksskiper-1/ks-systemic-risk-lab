# KS Systemic Risk Lab — приложение

## Запуск
    pip install -r requirements.txt
    streamlit run app.py

## Что в интерфейсе
- Переключатель «Режим»: «Дефолты» (пороговый каскад, протокол v1.3) и «Заражение (S)» (непрерывная модель v1.4-ext).
- Режим «Заражение (S)»: цвет и кольцо банка — доля потерянного капитала h на выбранном шаге; шаг — одна итерация ядра contagion.py, последний шаг — равновесие (итерации после того, как изменения стали меньше 1e-4, или после 20-й сведены в итог). Справа S_ind текущего шага (% суммарных активов), число банков с h ≈ 1, итог и A1S / A2S по шокам 0–15%. Под графом — S_ind после каждого шага. Помощь (резервы, поддержка, бюджет) в S отключена; выбор помощи сохраняется и вернётся в «Дефолтах». Демонстрационные сценарии рассчитаны на дефолты: выбор сценария переключает режим на «Дефолты». Карточка ρ — всегда опорный общий шок 1% без помощи, не состояние шага.
- Четыре «Демонстрационные сценарии» (кнопки сверху): выставляют сеть, шок и механизм, а текст рассказа считается из живых чисел.
- Кольцо вокруг банка: доля капитала, уже потерянная. Полное мигающее кольцо: банк упадёт на следующей волне.
- Наведите на банк: подсказка (активы, капитал, потерянная доля, кредиторы). Клик по банку: шок по этому банку.
- Под графом: столбики «сколько банков упало на каждой волне», клик по волне открывает шаг.
- Параметр α: от 0,1 до 0,6 (меньше 0,3 вне диапазона протокола; на экране это больше не подписывается).
- Пользовательские экраны без технических подписей (финал T5): нет блока «О модели», подписи о синтетической сети, упоминаний протоколов, версий, файлов и seed. Сети синтетические (25 банков, base seed 2026, номер сети задаёт поле «Номер сети»); модель показывает механизм, а не реальную банковскую систему. Флажок «Стандартный бюджет поддержки (3% капитала)» — бюджет по протоколу v1.3.
- Кнопка у графа: пауза / продолжить / показать сначала. Точки под ней переключают шаги.

## Раздел «Проверка гипотезы»
- Режим «Основной эксперимент» (по протоколу v1.3): число сетей выбирается автоматически (100 → 300 → 1000, пока ширина 95% ДИ не станет меньше δ), показываются критерии протокола (выполнено / не выполнено).
- Режим «Произвольное число сетей»: слайдер или поле (10–1000), на экране помечено «не заменяет основной эксперимент» (это не проверка по протоколу). Результаты по сетям кэшируются.
- Сетка чувствительности (27 ячеек) и дополнение по α = 0,1 и 0,2 лежат в precomputed.json; фрейм результатов 2860 px (максимум содержимого 2593 px при ширине 1920 + ~10%); пересчёт: python precompute.py (около 1,5 минуты).

## Файлы
- hypothesis.py, hyp_view.py, hyp_page.py   расчёт, отрисовка и страница раздела «Проверка гипотезы»
- precompute.py, precomputed.json           предрасчёт сетки и дополнения
- app.py            интерфейс (Streamlit)
- viz.py            граф с пошаговым каскадом и кривая C(s)
- cascade_trace.py  запись волн каскада (та же логика, что в engine.py)
- s_trace.py        пошаговая запись непрерывного заражения (та же итерация, что contagion.propagate_batch; итог сверяется с ядром)
- check_ui.py       проверки интерфейса (заглушка Streamlit, Node, headless Chromium); python check_ui.py --full-height — полный перебор высоты
- check_trace.py    проверка: волны совпадают с движком (ожидается 0 расхождений)
- engine.py         ядро (из проекта, без изменений логики)
- .streamlit/config.toml  светлая тема

## Деплой
Streamlit Community Cloud: залить папку в GitHub-репозиторий, указать app.py как основной файл.
Папка .streamlit должна лежать в репозитории.

## Если в браузере ошибка (removeChild / NotFoundError) или не жмутся кнопки
1. Открой http://localhost:8501 в окне инкогнито (расширения отключены). Если там всё работает, виновато расширение
   (чаще всего Dark Reader, Grammarly, переводчики): отключи его для localhost.
2. Chrome/Яндекс.Браузер: значок перевода в адресной строке -> «Никогда не переводить этот сайт».
3. Обнови страницу жёстко (Ctrl+F5) и перезапусти сервер.
4. Пришли версию: py -m streamlit --version
